# 挑戰者伺服器 S3

> 適用伺服器：TMS
>
> 適用版本：V280 CROWN
>
> 最後驗證：尚未完成官方原始活動頁核對
>
> 狀態：待驗證

## 一句話結論

挑戰者 S3 是期間限定的角色培養伺服器。玩家應先決定想取得的階級獎勵，再以等級與 Boss 點數規劃角色強度；若目標只是取得並強化時空挑戰者圖騰，可先以 40,000 點鑽石階級作為明確階段目標。

## 活動時間

- 實際開服：2026-06-24 維護後；開機公告記錄為 14:30。
- 培養與階級獎勵期限：2026-10-20 23:59。
- 開始轉移：2026-07-29 維護後。
- 最後轉移期限：2026-11-03 23:59。

官方活動頁搜尋資料曾顯示 2026-06-24 09:00 開始，但開機公告顯示伺服器於 14:30 開放。本頁採實際可登入時間，差異待官方原始頁核對。

## 適合誰

- 願意在期間限定伺服器重新培養角色的玩家。
- 希望取得時空挑戰者圖騰與階級成長資源的玩家。
- 希望利用 1.5 倍經驗及挑戰者階級增益培養新角色的玩家。

## 前置條件

- 在挑戰者伺服器建立角色；角色欄位共 5 個。
- 要參加同步的部分養成活動時，角色建立日期、等級和主要角色指定可能另有限制，必須逐一查看該子活動規則。
- 大師與挑戰者階級除點數外，還需要挑戰限定 Boss 凱伊。

## 活動流程

1. 在挑戰者伺服器建立並培養主要角色。
2. 完成等級、指定任務與 Boss 相關目標，累積挑戰者點數。
3. 依目標階級補足點數與凱伊擊破條件。
4. 在期限前領取階級獎勵。
5. 自 2026-07-29 起選擇適當時機將角色轉移至一般伺服器。
6. 在 2026-11-03 前完成最終轉移並清理商城保管箱、拍賣與其他保管內容。

## 達成條件

| 階級 | 點數門檻 | 額外條件 |
|---|---:|---|
| 青銅 | 5,000 | 無 |
| 白銀 | 10,000 | 無 |
| 黃金 | 15,000 | 無 |
| 白金 | 20,000 | 無 |
| 翡翠 | 30,000 | 無 |
| 鑽石 | 40,000 | 無 |
| 大師 | 65,000 | 擊敗普通凱伊 |
| 挑戰者 | 90,000 | 擊敗困難凱伊 |

目前已知點數來自等級、指定任務和 Boss 攻略；各項完整點數表尚待官方原始活動頁核對，因此本頁暫不提供精確配點試算。

## 獎勵與達成門檻

### 主要里程碑

| 階級 | 主要價值 |
|---|---|
| 黃金 | 取得時空挑戰者的圖騰 |
| 白金 | 取得第 1 張圖騰強化卷軸 |
| 翡翠 | 取得第 2 張圖騰強化卷軸及恢復方塊等資源 |
| 鑽石 | 取得第 3 張圖騰強化卷軸，完成圖騰的三次活動強化 |
| 大師 | 65,000 點加普通凱伊，取得恢復與附加方塊 |
| 挑戰者 | 90,000 點加困難凱伊，取得勳章與小屋家具 |

完整逐項獎勵已記錄在頁面 Front Matter。翡翠以上獎勵可在一般伺服器透過活動列表領取；實際可領取角色、道具期限與可否轉移仍應在領取前查看遊戲內說明。

## 每日與每週執行清單

### 每日

- 檢查活動 UI 中尚未完成的簽到或指定任務。
- 培養主要角色，推進下一個等級點數門檻。
- 領取有當日到期或無法補領的獎勵。

### 每週

- 在重置前完成能提供挑戰者點數的 Boss。
- 檢查下一階級尚缺多少點數，避免只練等卻漏掉 Boss 點數。
- 檢查凱伊擊破進度及組隊安排。
- 檢查挑戰者限定的師徒暴風修練、命運祕笈與幸運箱等子活動；這些應另建獨立頁面，避免混淆規則。

## 完成天數、進度計算與容錯

目前無法只依階級門檻推算最低完成天數，因為完整點數來源、每週可取得上限及玩家可擊敗的 Boss 難度尚未完成官方核對。

在點數表補齊前，玩家應使用以下方式規劃：

```text
目前總點數
+ 尚可取得的等級點數
+ 剩餘週數 × 每週可穩定取得的任務／Boss 點數
= 預估最終點數
```

若預估值只比目標略高，應保留至少一次每週重置的容錯，不要把完成時間壓在 2026-10-20 最後一天。

## 建議完成路線

### 目標：取得圖騰

先達 15,000 點黃金取得圖騰，再推進至 40,000 點鑽石，取得三張強化卷軸。這是目前最清楚、也最容易向回谷玩家說明的階段目標。

### 目標：取得一般伺服器成長資源

以 30,000 點翡翠或 40,000 點鑽石作為目標。先確認自己可穩定擊敗的 Boss，再決定是否值得繼續投入到 65,000 點。

### 目標：大師或挑戰者

除了 65,000／90,000 點，還必須處理普通／困難凱伊。這兩個目標不只是累積時間問題，也涉及裝備、六轉進度、隊伍與操作；在建立完整點數及凱伊攻略前，本頁不宣稱無課或特定戰力一定可完成。

## 不同玩家的建議

- **剛回谷玩家**：先以黃金取得圖騰，再評估是否能穩定完成每週 Boss。
- **有限時間玩家**：優先確保每日不可補領項目和每週 Boss，不要只追求練等速度。
- **以轉移角色為目的的玩家**：提前確認目標一般伺服器與轉移限制，並在最後期限前清空無法跟隨轉移的保管內容。
- **高階挑戰玩家**：大師與挑戰者需另行規劃凱伊，本頁暫不取代專門 Boss 攻略。

## 常見錯誤

- 把 40,000 點誤認為只取得圖騰；圖騰在 15,000 點取得，後續三個里程碑提供強化卷軸。
- 只計算點數，忘記大師與挑戰者另有凱伊擊破條件。
- 把活動結束日與最後角色轉移日視為同一天。
- 角色進入轉移區後才發現不能繼續培養或使用部分保管功能。
- 未在伺服器結束前領出商城保管箱或拍賣中的道具。
- 把其他伺服器或 S1、S2 的點數表直接套用到 S3。
