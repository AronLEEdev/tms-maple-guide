# 挑戰者伺服器 S3

## 來源摘要

遊戲橘子發布的 TMS 挑戰者伺服器 S3 官方活動頁，包含本季伺服器規則、任務、階級、獎勵、商店、幸運箱、可疑的結界、角色轉移及凱伊相關活動。

## 支援的結論

- 活動時間為 2026-06-24 09:00 至 2026-10-20 23:59。
- 狩獵任務每天一次、每週最多五次，每次狩獵 1,000 隻怪物取得 300 枚挑戰者硬幣。
- 等級任務和單人 Boss 任務提供挑戰者點數與硬幣。
- 青銅至挑戰者階級的門檻與獎勵。
- 角色轉移期間、資格及無法轉移的狀態與道具。
