# TMS 楓谷行動指南

一個開源、可追溯、AI 友善的《新楓之谷》台灣伺服器（TMS）玩家行動知識庫，專注於當期活動、回谷路線、練級、任務與戰力提升。

## 專案目標

本專案希望協助玩家回答：

> 我是剛回谷或剛接觸當期活動的玩家，依照我的等級、進度與投入程度，現在最應該做什麼？

我們不只整理資訊，也會標示適用伺服器、版本、最後驗證日期及資料來源，並區分官方規則、玩家實測、編輯建議與待驗證內容。

## 目前狀態

專案正在建立基礎架構，尚未發布可供玩家採用的正式攻略。現階段內容不得視為當前 TMS 遊戲建議。

## 內容結構

- `內容/`：活動、攻略、版本與術語等玩家可閱讀內容。
- `資料/`：會被多篇內容共用的結構化 YAML 資料。
- `來源/`：官方、社群及其他伺服器來源紀錄。
- `範本/`：活動、攻略、版本、來源與實測範本。
- `結構定義/`：Front Matter 與 YAML 的 Schema。
- `程式/`：格式、來源、期限和連結檢查工具。
- `素材/`：本專案有權保存的圖片與其他素材。

所有正式內容與目錄使用繁體中文及台灣常用語；技術欄位與穩定 ID 可以保留英文。

## 貢獻

專案尚處於早期階段。提交內容前請先閱讀 [貢獻指南](CONTRIBUTING.md)。任何重要規則、數值、活動期限或版本差異都必須附上可追溯來源。

## 本機驗證

```bash
npm install
npm run validate
```

驗證器會檢查正式內容的 Front Matter、Schema、穩定 ID、來源引用及活動時間。
